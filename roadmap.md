# IME – Integrated Market Engine: Build Roadmap

- [ ] DB schema: ime_symbols (watchlist), ime_decisions (history), ime_settings (Telegram chat id, alert prefs)
- [ ] Auth: email/password + Google sign-in (required for per-user data)
- [ ] IME engine: 5 deterministic engines (Core Data, Market Maker, Movement, Price Behavior, Decision)
- [ ] Market data fetcher: MenthorQ-compatible API via secret key; simulated demo fallback
- [ ] Dashboard: watchlist, run analysis, decision cards, history
- [ ] Telegram alerts on AGGRESSIVE_ENTRY / CONSERVATIVE_ENTRY decisions
- [ ] Head metadata + final verification
